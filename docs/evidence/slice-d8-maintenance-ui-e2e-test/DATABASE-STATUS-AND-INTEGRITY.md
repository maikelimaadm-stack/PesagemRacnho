# DATABASE-STATUS-AND-INTEGRITY

## Status exibido
OK / Atenção / Erro + “funcionando/verificar”

## Stats
Pesagens, apartações, sanidades (eventos), embarques, tamanho aproximado do banco

## Integrity check
`runIntegrityCheck()` — pragma integrity_check

## Quick check
`runQuickCheck()` — pragma quick_check

## Mensagens
- `Banco íntegro.`
- `Foi encontrado um problema. Faça backup e envie o relatório técnico.`

## Erros
Sem stack trace; toast com mensagem segura; botão Copiar diagnóstico
