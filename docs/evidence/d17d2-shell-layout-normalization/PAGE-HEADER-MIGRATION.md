# Migração dos cabeçalhos de página

As três páginas usam `ModeloBase1PageHeader`.

## Regra única

- altura mínima desktop: `44px`;
- altura mínima mobile: `48px`;
- padding: `5px 10px` desktop e `5px 8px` mobile;
- título: `14px/17px`, peso `700`;
- título mobile: `13px`;
- subtítulo: `10px/13px` e oculto no mobile para preservar espaço útil;
- raio: `12px` desktop e `10px` mobile;
- border e sombra pelos tokens ModeloBase1.

## Títulos padronizados

- Pesagens Individuais;
- Lançamento de Pesagens;
- Backup e Manutenção.

Não restaram títulos estruturais `text-lg` diferentes entre essas três páginas.
