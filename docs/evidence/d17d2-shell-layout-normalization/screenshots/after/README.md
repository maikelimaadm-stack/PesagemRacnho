# Capturas depois

As capturas pós-implementação não foram produzidas nesta execução.

O navegador integrado negou acesso a `http://127.0.0.1:5173` por política automática. A própria resposta de segurança proibiu Playwright, CDP, navegador externo automatizado ou outra superfície de browser como alternativa. Não foi criada evidência simulada.

O build e a suíte completa passaram. Para fechar a matriz visual, ainda são necessárias capturas manuais/autorizadas em 1440x900, 1366x768 e 390x844 nas três rotas.
