# Guia rápido — Pesagens Individuais

Sistema **offline e gratuito** para controlar pesagens individuais no computador. Não precisa de internet nem de conta.

## Como abrir

1. Clique no atalho **Pesagens Individuais** na área de trabalho, ou
2. Abra pelo Menu Iniciar.

## Como lançar uma pesagem

1. No menu superior, abra **Lançar Pesagens**.
2. Preencha os dados do animal e o peso.
3. Salve o lançamento.

## Como consultar registros

1. Abra **Pesagens Individuais**.
2. Use os filtros da tela para encontrar o que precisa.

## Embarque

Na tela de lançamento, use a documentação de embarque para organizar saídas (GTA, NFe, etc.).

## Como fazer backup

1. Abra **Manutenção** no menu.
2. Clique em **Criar backup completo**.
3. Confira nome, tamanho e SHA-256 na mensagem de sucesso e no catálogo da tela.

## Como verificar se o banco está saudável

1. Abra **Manutenção**.
2. Clique em **Verificar integridade**.
3. Se aparecer “Banco íntegro.”, está tudo certo.

## Se algo der errado

1. Faça um **backup** imediatamente.
2. Anote a mensagem de erro (use **Copiar diagnóstico** na tela de Manutenção).
3. Não apague a pasta de dados do programa nem edite manualmente o backup JSON.
4. Consulte também `BACKUP-E-RESTAURACAO.md` e `INSTALACAO-WINDOWS.md`.
